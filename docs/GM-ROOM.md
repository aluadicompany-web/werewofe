# ห้อง GM สำหรับทดสอบกับบอท

## เปิดใช้เว็บจริง

1. ไปที่ Render Dashboard เลือกบริการ **moonfall-realtime** → **Environment**
2. เพิ่ม **Key: `GM_ADMIN_KEY`** ตั้ง Value เป็นรหัสลับส่วนตัว 24–256 ตัวอักษร แนะนำรหัสสุ่ม 32 ตัวขึ้นไป อย่าส่งค่าในแชตหรือ commit ลง GitHub
3. บันทึกและรอ service deploy/กลับมา Live การ restart จะทำให้ห้องที่กำลังเล่นหายเช่นเดียวกับระบบเดิม
4. เปิดหน้าเกม Cloudflare Pages หรือ Netlify กด **GM · ห้องทดสอบ** ใส่ชื่อและรหัสที่ตั้งไว้ แล้วสร้างห้อง

รหัสอยู่เฉพาะ backend Render ไม่ใช่ Environment ของ Netlify และไม่ใช่ `PUBLIC_GAME_SERVER_URL` ไม่ตั้งรหัสหรือใช้รหัสสั้นกว่า 24 ตัวจะปิดการสร้างห้อง GM โดยห้องเล่นปกติไม่ถูกปิด รหัสถูกตรวจบนเซิร์ฟเวอร์ด้วยการเปรียบเทียบ digest แบบ constant-time และจำกัดคำขอรหัสผิด รหัสไม่ถูกส่งให้ผู้เล่นอื่นหรือเก็บใน localStorage/sessionStorage

สำหรับเครื่องพัฒนา ให้ตั้ง `GM_ADMIN_KEY` ใน process environment ก่อน `npm start` หรือใช้ Node `--env-file` ของคุณเอง `npm start` ไม่อ่านไฟล์ `.env` อัตโนมัติ ไม่มีรหัสตั้งต้นจริงใน repository

## วิธีใช้

- **เติมบอทให้ครบ 6/9/12 คน** นับรวมที่นั่ง GM และมนุษย์คนอื่นแล้ว เช่น GM คนเดียวเติมครบ 6 จะได้บอท 5 ตัว
- **+ บอท 1 ตัว / ลบบอททั้งหมด** ใช้ในห้องรอ ไม่เกิน 12 คน เริ่มเกมต้องมีอย่างน้อย 6 คน
- **บทบาทของ GM** เลือกในห้องรอก่อนกดพร้อม ใช้ได้เฉพาะบทบาทที่มีในชุดของโหมดและจำนวนคนปัจจุบัน หรือเลือกสุ่มตามปกติ จำนวนบทบาทรวมไม่เปลี่ยน และคงตัวเลือกไว้เมื่อรีเซ็ต ถ้าลดจำนวนคนจนบทบาทไม่มีในชุดจะเริ่มไม่ได้ ต้องเลือกใหม่หรือเพิ่มผู้เล่น Classic: นายพรานต้อง 9–12 คน ผู้อาวุโสต้องครบ 12 คน ส่วน Advanced ใช้ 9–12 คนและชุดตาม [ADVANCED.md](ADVANCED.md)
- บอทพร้อมอัตโนมัติ คุณและมนุษย์คนอื่นกด **ฉันพร้อมแล้ว** แล้ว GM กด **เริ่มคืนแรก**
- **ความเร็วทดสอบ 1/5/20 เท่า** เลือกก่อนเริ่ม ใช้เฉพาะห้อง GM ไม่เปลี่ยนเวลาของห้องปกติ และจะยกเลิกความพร้อมของคนเพื่อให้รับทราบเวลาที่เปลี่ยน
- **แสดงบทบาทและคำสั่งทุกคน** เปิด debugger ส่วนตัวและแสดงบทบาทบนการ์ด เฉพาะ GM เท่านั้นที่ได้รับข้อมูลนี้ เหมาะกับการทดสอบ ไม่ใช่การแข่งขัน
- **ให้บอทส่งคำสั่งตอนนี้** ทำให้บอทที่ยังไม่ได้กระทำส่งคำสั่งทันที แต่ไม่จบช่วงและไม่สุ่มใหม่ซ้ำบอทที่ส่งแล้ว
- **จบช่วงนี้** ให้บอทส่งที่ยังขาด แล้วจบช่วงปัจจุบันผ่าน resolver ปกติ ทดสอบกติกาได้เร็วโดยไม่รอ timer
- **รีเซ็ตกลับห้องรอ** หยุดแมตช์ ล้างบทบาท/คะแนน/แชต คงสมาชิกและบอทไว้ เริ่มสุ่มบทบาทใหม่ได้
- **ปิดห้อง GM** ปิดเฉพาะห้องทดสอบนี้และนำทุกคนออก ไม่ปิดเซิร์ฟเวอร์หรือห้องอื่น

GM ยังเป็นผู้เล่นหนึ่งที่นั่ง จึงใช้พลังและโหวตเองได้ หากถูกกำจัดยังควบคุมการทดสอบได้ ผู้เข้าห้องผ่านรหัส/ลิงก์เป็นผู้เล่นธรรมดา ไม่ได้สิทธิ์ GM แม้พยายามส่งคำสั่งเอง ผู้เล่นห้องปกติไม่มี debugger และเปลี่ยนห้องปกติให้เป็นห้อง GM ไม่ได้

เมื่อ GM หลุด สิทธิ์จะไม่โอนไปใคร กลับด้วยแท็บเดิมเพื่อกู้ที่นั่ง/สิทธิ์โดยใช้ session token เดิมและหมุน token ใหม่ ไม่ต้องพิมพ์ master key ซ้ำ แต่การสร้างห้อง GM ใหม่ต้องยืนยันรหัสใหม่ทุกครั้ง ผู้ที่ถือรหัสเดียวกันสามารถสร้างห้องทดสอบของตนเอง จึงไม่ควรแบ่งปันรหัส

## พฤติกรรมบอท

บอททำงานบนเซิร์ฟเวอร์และใช้ `act`/resolver เดียวกับมนุษย์ สุ่มด้วย `node:crypto` ไม่แก้ alive, role หรือผลโหวตเอง

- หมาป่าและจ่าฝูงเลือกเฉพาะผู้มีชีวิตที่ไม่ใช่หมาป่าร่วมทีม
- ผู้พิทักษ์เลือกปกป้องคนอื่น แม่มดสุ่มข้าม/ยาช่วยชีวิตที่มีเหยื่อ/ยาพิษที่เหลืออยู่ หนึ่งชนิดต่อช่วงตัดสินใจ
- ผู้หยั่งรู้ไม่ตรวจตัวเอง หมอป้องกันตัวเองได้และไม่เลือกคนเดิมสองคืนติดกัน
- โหวตผู้มีชีวิตหรืองดออกเสียง รอบสองเลือกได้เฉพาะผู้ที่เสมอ
- นายพรานที่ตายและได้สิทธิ์ยิงจะสุ่มเป้าหมายหรือข้ามภายในช่วงปฏิกิริยา
- หนึ่งคำสั่งต่อช่วง ไม่สุ่มทับซ้ำทุก tick ผู้ตายไม่ใช้พลัง/โหวต ยกเว้นนายพรานตามกฎ
- ไม่สร้างข้อความแชต ไม่เล่นกลยุทธ์หรือพิสูจน์ความสมดุลเกม

ห้องและสิทธิ์ยังอยู่ในหน่วยความจำ รีสตาร์ตเซิร์ฟเวอร์แล้วหาย ห้องที่ไม่มีมนุษย์เชื่อมต่อ 30 นาทีถูกลบ บอทไม่ทำให้ห้องค้างตลอดไป

## ตรวจสอบ

`npm run check`, `npm test`, `npm run test:gm` และ `npm run test:browser` ใช้ได้โดยไม่รู้รหัส GM จริง ชุด GM ใช้ fixture ที่ตั้งเฉพาะ child test server ไม่ใช่รหัสสำหรับเว็บไซต์จริง ภาพที่บันทึกแสดงเฉพาะห้องทดสอบและไม่แสดงรหัส
