# Advanced — โหมดทดลอง 9–12 คน

อิง Experimental Advanced presets และ interaction จาก Werewolf_Online_Codex_Spec.docx ที่ผู้ใช้แนบ เปิดให้เล่นแบบ Casual ตามคำขอเพิ่มโหมด Advanced ไม่เปิด Chaos/Jester หรือ ranked และยังไม่มีข้อมูลยืนยันสมดุลจากผู้เล่นจริง

## เริ่มเล่น

เจ้าของห้องเลือก **โหมดเกม → Advanced · ทดลอง** ในห้องรอ เลือกเวลา แล้วทุกคนกดพร้อมใหม่ ต้องมี 9–12 คน คลาสสิกยังรองรับ 6–12 คนเหมือนเดิม การเปลี่ยนโหมด/เวลายกเลิกความพร้อมของมนุษย์ทั้งหมด บอทยังพร้อมอัตโนมัติ เปลี่ยนโหมดระหว่างแมตช์ไม่ได้

## บทบาทใหม่

- **ผู้พิทักษ์ (Guard):** กลางคืนเลือกปกป้องคนอื่น 1 คน ห้ามตัวเอง เลือกคนเดิมหลายคืนได้ ถ้าหมาป่าจะฆ่าคนนั้น ผู้พิทักษ์เสียสละแทน ถ้ามีหมอหรือยาช่วยชีวิตป้องกันอยู่แล้ว ผู้พิทักษ์ไม่ต้องเสียสละ การป้องกันนี้ไม่กันพิษหรือประหาร
- **แม่มด (Witch):** ไม่มีการกระทำในช่วงกลางคืนหลัก หลังล็อกคำสั่งหมาป่าและพลังอื่น มีช่วงตัดสินใจเพิ่ม **12 วินาที** เห็นเหยื่อหมาป่าเฉพาะแม่มด เลือกยาช่วยชีวิตเหยื่อคืนนั้น (ช่วยตัวเองได้) หรือยาพิษใส่ผู้มีชีวิตหนึ่งคน รวมตัวเองได้ ยาแต่ละชนิดมี **1 ขวดต่อเกม** ใช้ได้เพียงชนิดเดียวต่อคืน กดชนิดยา → เลือกเป้าหมาย → ยืนยัน หรือข้าม เปลี่ยนคำสั่งได้ก่อนหมดเวลา หักยาเฉพาะคำสั่งสุดท้ายเมื่อคลี่คลายผล ไม่หักตอนคลิก/ส่งซ้ำ หากไม่มีเหยื่อจะใช้ยาช่วยชีวิตไม่ได้ ยาไม่ฟื้นคนตายคืนก่อน และไม่บอกว่าหมอได้ช่วยเหยื่ออยู่แล้วหรือไม่
- **จ่าฝูงหมาป่า (Alpha Wolf):** อยู่ฝ่ายหมาป่า นับเป็นหมาป่าสำหรับเงื่อนไขชนะ แชตฝูง เห็นหมาป่าร่วมทีม และร่วมลงคะแนนโจมตีเหมือนหมาป่าปกติ แต่ผู้หยั่งรู้ได้ผล **ไม่ใช่หมาป่า / 👍** ดังนั้นผลตรวจนี้ไม่รับรองว่าเป็นฝ่ายหมู่บ้านใน Advanced ไม่มีพลังฆ่าเพิ่ม

ช่วงแม่มด คำสั่งกลางคืนหลักถูกล็อก ทุกคนรอและเห็นเวลาเดียวกัน ไม่มีปุ่มใช้พลัง/โหวตสำหรับคนอื่น เฉพาะแม่มดได้รับเหยื่อ จำนวนยา และคำสั่งของตัวเอง แม้ใช้ยาหมดแล้ว แม่มดที่ยังมีชีวิตยังมีช่วงนี้ให้ข้ามได้ เพื่อไม่ใช้ระยะเวลาเปิดเผยจำนวนยาที่เหลือ หากแม่มดหลุดหรือไม่เลือกจะข้ามเมื่อหมดเวลา

## ลำดับผลกลางคืน

1. ล็อกหมาป่า/หมอ/ผู้พิทักษ์/ผู้หยั่งรู้ เก็บผลตรวจไว้บนเซิร์ฟเวอร์
2. ถ้ามีแม่มดที่มีชีวิต รอการเลือกยาหรือข้ามภายใน 12 วินาที
3. หมอหรือยาช่วยชีวิตหยุดการโจมตีหมาป่าก่อน จากนั้นผู้พิทักษ์เสียสละ แล้วจึงเกราะผู้อาวุโส หากไม่มีการป้องกันจึงเสียชีวิต
4. ยาพิษมีผลอิสระ ข้ามหมอ ผู้พิทักษ์ และเกราะ ไม่ฆ่าซ้ำ หากผู้พิทักษ์โดนพิษพร้อมเสียสละยังช่วยเป้าหมายได้ แต่เสียชีวิตเพียงครั้งเดียว
5. นายพรานที่ถูกหมาป่าฆ่าหรือถูกประหารได้ยิง 15 วินาที หากถูกพิษจะไม่ได้ยิง **รวมกรณีได้รับทั้งพิษและการโจมตีหมาป่าถึงตายในคืนเดียวกัน** เลือกกฎนี้เพื่อให้คำว่า “พิษไม่กระตุ้นนายพราน” ชัดเจน
6. ผู้หยั่งรู้ได้ผลเฉพาะถ้ารอดจนจบทั้งคืนและปฏิกิริยานายพราน แล้วประกาศผู้ตายและตรวจชนะครั้งเดียวหลังผลครบ หากไม่มีผู้รอดชีวิตเสมอ จ่าฝูงยังมีชีวิตอยู่ฝ่ายหมู่บ้านยังไม่ชนะ

โหวตคลิกครั้งเดียว รอบสองไฮไลท์ผู้เสมอ เครื่องหมายโหวตส่วนตัว และประวัติผู้หยั่งรู้ข้างเลขที่นั่งยังทำงานเหมือนคลาสสิก เลือกให้ทั้งสองโหมดเปิดเผยบทบาทผู้ตายเหมือนระบบเดิม ไม่เปิดเผยสาเหตุการตาย เป้าหมายป้องกัน หรือผู้ใช้ยาแก่คนอื่น

## ทดลองด้วย GM

ใช้รหัส GM เดิม สร้างห้องใหม่ เลือก Advanced แล้วเติมบอทให้ครบ 9 หรือ 12 คน หากต้องการชุด 10/11 ให้เติม 9 แล้วเพิ่มบอทอีก 1/2 ตัว เลือกโรลตัวเองจากชุดตามจำนวนคน ปุ่มเร่งช่วง บอทสุ่มยา และ debugger ใช้กับ Advanced ได้ การเลือกโรลที่หายไปหลังเปลี่ยนโหมด/จำนวนคนจะบล็อกเริ่มจนเลือกใหม่ ไม่เปลี่ยนจำนวนบทบาทในชุด

## ตรวจสอบ

- `npm run check` — syntax
- `npm test` — Classic regressions, exact Advanced decks, Guard/Doctor/armor, Witch resource/replay/privacy, simultaneous poison and Hunter, Alpha/Seer/parity, 120 bot simulations across Advanced sizes, real 12-client Socket.IO with reconnect and AFK Witch
- `npm run test:advanced` — static build แยก origin backend, GM/ผู้เข้าร่วม, เลือกโหมด/ขั้นต่ำ, Guard, Witch save/poison/reconnect/private HUD, Alpha chat, full Advanced match/rematch/switch back, desktop/mobile screenshots
- `npm run test:browser`, `npm run test:gm`, `npm run test:vote`, `npm run test:seer` — regression ของ flow เดิม

การทดสอบอัตโนมัติบน Chromium และบอตสุ่มไม่แทนการทดลอง bluff กับคนจริง ต้องลองเล่นแต่ละชุดก่อนปรับสมดุล ห้องยังอยู่ในหน่วยความจำและหายเมื่อ Render restart เหมือนเดิม
