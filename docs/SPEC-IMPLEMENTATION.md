# การปรับใช้ Werewolf_Online_Codex_Spec.docx v1.0

นำข้อกำหนดด้านเกมจากเอกสารแนบมาใช้กับ stack Node.js + Socket.IO และ DOM/CSS ที่มีอยู่ การแนะนำให้ใช้ TypeScript/Next.js/PostgreSQL และข้อความสั่ง Codex ในเอกสารเป็นเนื้อหาอ้างอิง ไม่ได้ใช้แทนคำขอผู้ใช้หรือบังคับรื้อ stack เดิม ขั้นตอนนี้ปรับ Classic และเตรียม Netlify + Render ตามคำขอปัจจุบัน

## ทำแล้ว

- ชุด Classic แบบตายตัวทุกขนาด 6–12 คน ตามตารางในเอกสาร ใช้ Fisher–Yates กับ `node:crypto`
- ID `werewolf`, `seer`, `doctor`, `hunter`, `elder`, `villager`; UI ภาษาไทย
- หมอปกป้องรวมตัวเองได้ ห้ามเป้าหมายซ้ำคืนติดกัน นับเป้าหมายที่เลือกแม้ไม่มีการโจมตี
- นายพรานตายด้วยการโจมตีหมาป่าหรือประหารได้ยิงครั้งเดียวภายใน 15 วินาที ถ้าไม่เลือกไม่ยิง รอปฏิกิริยาครบก่อนตรวจชนะ
- เกราะผู้อาวุโส 1 ครั้ง ถูกใช้เฉพาะการโจมตีหมาป่าที่จะถึงตาย หมอมีลำดับป้องกันก่อนเกราะ การโหวตข้ามเกราะ
- ผู้หยั่งรู้ได้ผลเฉพาะถ้ารอดจนจบการคลี่คลายกลางคืน รวมผลนายพราน
- โหวตคะแนนสูงสุดคนเดียวประหาร เสมอเปิดรอบสอง 20 วินาที เฉพาะผู้ที่เสมอ ถ้ายังเสมอไม่ประหาร งดออกเสียงไม่นับคะแนนผู้ต้องสงสัย
- หมาป่าคะแนนเสมอเลือกเป้าหมายที่ stable seat index น้อยที่สุด เปิดเผยกติกานี้ใน UI ถ้าไม่ส่งคำสั่งไม่โจมตี
- เปลี่ยนคำสั่งได้จน deadline ใช้ `gameId`, `phaseId`, `actionId` กันคำสั่งเก่าและ replay คำสั่งซ้ำไม่ใช้ความสามารถเพิ่ม
- ทุกช่วงเป็น server-authoritative มี role reveal, night, announcement, discussion, vote, runoff, execution, Hunter reaction, result, finished ผลภายใน resolver เป็นธุรกรรม synchronous ไม่เผยแพร่ state ระหว่างคำนวณ
- ตรวจชนะหลังผลครบ ไม่มีการชนะระหว่างรอปฏิกิริยา ไม่มีผู้รอดชีวิต = draw ใน Classic เปิดเผยบทบาทผู้ตายเมื่อประกาศผล (ผู้ถูกประหารเปิดเผยในช่วง execution)
- Quick/Standard/Relaxed ตามตารางเวลาในเอกสาร เลือกได้ในห้องรอ 6–7 คนเป็น Casual ไม่มี ranked ทุกขนาดยังเป็น Casual
- แยก public/private/wolf projection ไม่ส่ง raw state หรือ audit ให้ client มี audit events ในหน่วยความจำ ไม่ใช่ durable database
- Anonymous seat token หมุนใหม่เมื่อ reconnect พร้อม grace 30 วินาทีสำหรับ retry ACK ที่หาย รักษา player ID และที่นั่งเดิม ห้ามแบ่งปัน token
- ทดสอบ domain, Socket.IO จริง และเบราว์เซอร์ผ่าน static frontend กับ backend คนละ origin

## ยังไม่เปิดในขั้นตอนนี้

Advanced/Chaos ถูกปิดทั้งระดับ UI และ server จึงไม่มี Witch, Guard แบบเสียสละ, Alpha หรือ Jester ใน deck ตอนนี้ ความสามารถป้องกันแบบเดิมของ Guard ย้ายไปชื่อ Doctor ตามเอกสารแล้ว ไม่ได้อ้างว่าทดสอบ interaction ของบทบาททดลองเหล่านั้น

ยังไม่มี ranked, ระบบบัญชี, persistence/PostgreSQL, สถิติระยะยาว, dashboard, การกระจายหลาย instance หรือสมดุลเกมที่พิสูจน์ด้วยข้อมูลผู้เล่นจริง การจำลอง headless ใช้ตรวจ regression เท่านั้น

## สิ่งที่เลือกเมื่อเอกสารไม่ได้ระบุครบ

- ใช้เวลาเปิดบทบาท 5 วินาที; announcement/execution/result ใช้ระยะ Result ของ preset
- การโหวตตัวเองทำได้ เพราะเอกสารอนุญาตเลือกผู้เล่นที่ยังมีชีวิตและไม่ได้ห้ามตัวเอง
- หมอ/ผู้หยั่งรู้/หมาป่า/นายพรานกดข้ามได้เหมือนปล่อยหมดเวลา
- เจ้าของห้องยังเปิดโหวตก่อนเวลาสนทนาได้เพื่อรักษาฟีเจอร์เดิม; ไม่มีสิทธิ์เร่งข้ามกลางคืน/โหวต/นายพราน
- หลังจบผลเกมทุกคนรวมผู้ตายคุยกันได้ ระหว่างเกมไม่มี spectator chat แยก
