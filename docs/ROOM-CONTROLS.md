# ผู้คุมเกม สีเฟส และการเลือกเป้าหมาย

## ที่นั่ง Host / GM นอกแมตช์

ในห้องรอ เจ้าของห้องหรือ Host กด **เป็น Host ผู้คุมเกม (ไม่ร่วมเล่น)** หรือ **เป็น GM ผู้คุมเกม (ไม่ร่วมเล่น)** ที่แผงเหนือกระดานได้ ผู้คุมแสดงแยกจากที่นั่งผู้เล่น ไม่รับบทบาท ไม่ต้องกดพร้อม ไม่เป็นเป้าหมาย ไม่ใช้พลัง ไม่โหวต และไม่นับเงื่อนไขชนะ

- Classic ยังต้องมี **ผู้เล่นจริงหรือบอท 6–12 คน**; Advanced ต้อง **9–12 คน** นอกเหนือจากผู้คุม เช่น Host 1 คน + ผู้เล่น 6 คน = ผู้เปิดเว็บ 7 คน
- ห้องมีที่นั่งผู้คุมได้สูงสุด 2 คน แยกจากจำนวนผู้เล่นสูงสุด 12 คน
- สลับกลับเป็นผู้เล่นได้เฉพาะห้องรอและมีที่นั่งว่าง การสลับยกเลิกความพร้อมของมนุษย์ หมายเลขผู้เล่นเรียงใหม่เฉพาะห้องรอ ส่วน seat UUID/ตัวตนสำหรับ reconnect ยังเดิม
- เจ้าของห้องปกติยังร่วมเล่นได้ตามเดิม ไม่บังคับทุกห้องต้องมีผู้คุมแยก
- GM ยังเลือกร่วมเล่นและกำหนดโรลตัวเองได้ หากเปลี่ยนเป็นผู้คุมจะยกเลิกโรลที่เลือก ไม่มี dropdown โรลจนกว่าจะกลับเป็นผู้เล่น
- GM นอกแมตช์เติมบอทครบ 6/9/12 ได้ตามจำนวนผู้เล่นเป้าหมาย เช่น เติมครบ 12 = บอท 12 ตัว ไม่ใช่ 11 ตัว
- Host ผู้คุมปกติมีปุ่ม **จบช่วงนี้** พร้อมยืนยัน ใช้คำสั่งที่รับแล้วและ resolver ปกติ ไม่เห็นบทบาทลับของคนที่ยังไม่เปิดเผย ส่วน GM ที่ยืนยันรหัสเดิมมี debugger เห็นบทบาท/คำสั่งตามเดิม
- รีเฟรชแท็บเดิมเพื่อกลับที่นั่งผู้คุมด้วย token ที่หมุนใหม่ ไม่มีการเก็บรหัส GM ในเบราว์เซอร์
- เมื่อเจ้าของห้องปกติหลุด Host ที่รับช่วงยังดูแลห้องได้ เจ้าของเดิมที่กลับมายังมีสิทธิ์จัดการห้องด้วย กรณีเจ้าของเดิมออฟไลน์ในห้องรอ Host สามารถนำที่นั่งเดิมออกเพื่อกู้ห้องได้ ส่วน GM ไม่โอนสิทธิ์ให้คนอื่น

## เตะผู้เล่น

เจ้าของห้องและ Host เห็นปุ่ม **×** มุมขวาบนของการ์ดผู้เล่น กดแล้วมีข้อความยืนยัน ยกเลิกจะไม่ส่งคำสั่งเตะ ปุ่มนี้แยกจากปุ่มเลือกเป้าหมาย จึงใช้ได้แม้การ์ดเลือกโหวต/ใช้พลังไม่ได้ ผู้เล่นทั่วไปไม่เห็นปุ่ม และเซิร์ฟเวอร์ปฏิเสธคำสั่งที่ไม่มีสิทธิ์

- เตะได้ทั้งผู้เล่นออนไลน์ ออฟไลน์ และบอท ไม่เตะตัวเองหรือ GM เจ้าของห้อง และไม่เตะเจ้าของห้องที่กำลังเชื่อมต่อ
- ห้องรอ: นำที่นั่งออกและยกเลิกความพร้อมของมนุษย์ ต้องมีจำนวนคนครบตามโหมดจึงเริ่มได้
- ระหว่างแมตช์: ผู้ถูกเตะกลับหน้าแรกทันที ล้าง session token และปิดสิทธิ์กลับที่นั่งเดิม เก็บการ์ดของแมตช์ไว้เป็นถูกนำออกเพื่อไม่เปลี่ยน deck กลางเกม ไม่นับเป็นผู้มีชีวิต และนำการ์ดออกเมื่อกลับห้องรอ
- ล้างคำสั่งของคนที่ถูกเตะ รวมคำสั่ง/คะแนนที่เลือกคนนั้น เป้าหมายหมาป่า/ยาที่เกี่ยวข้องในช่วงล็อกถูกยกเลิกโดยไม่ใช้ยาเพิ่ม ไม่ให้พลังยิงนายพรานจากการเตะ หากกำลังรอนายพรานที่ถูกเตะ จะจบปฏิกิริยาโดยไม่ยิง
- ตรวจชนะหลังผลกลางคืน/ประหารที่ค้างครบตามกติกา หากไม่มีผลค้างในช่วงกลางวันสามารถจบแมตช์ได้ทันทีเมื่อเงื่อนไขชนะครบ
- การเตะเป็นการนำออกและเพิกถอนที่นั่ง ไม่ใช่ระบบแบนบัญชี ในห้องรอผู้ที่ถูกเตะยังเข้าร่วมใหม่ด้วยตัวตนใหม่ได้ เพราะเกมไม่มีระบบบัญชี

## สีและเครื่องหมาย

- กลางวัน: พื้นหลังและกรอบกระดานโทนเหลืองส้ม พร้อมป้าย **☀ กลางวัน**
- กลางคืน: น้ำเงินม่วง พร้อม **☾ กลางคืน** รวมช่วงแม่มดและปฏิกิริยานายพรานที่มาจากกลางคืน ปฏิกิริยาที่มาจากประหารใช้สีกลางวัน ห้องรอ/ผลจบใช้สีปกติ
- โหวตเช้า/รอบสอง: คลิกเพื่อส่งทันที กรอบเขียวและ ✓ กลางการ์ดของเป้าหมายที่คุณโหวต เห็นเฉพาะคุณ เปลี่ยนเป้าหมาย/งดออกเสียงได้จนหมดเวลา ยังนับผลเมื่อจบช่วง
- ใช้พลัง: คลิกผู้เล่นเพื่อส่งทันที **ไม่มีปุ่มยืนยันซ้ำ** แสดงกรอบเขียวและไอคอนพลังเฉพาะเจ้าตัว เช่น 🔮 / 💊 / 🛡️ / 🧪 / ☠️ / 🏹 / 🐾 แสดงหลังเซิร์ฟเวอร์รับคำสั่ง เปลี่ยนได้จนหมดเวลา ข้ามใช้พลังได้ทันทีเช่นกัน นายพรานใช้การคลิกเดียวเหมือนกัน
- แม่มดยังต้องเลือกชนิดยาก่อนคลิกเป้าหมาย หักเฉพาะยาจากคำสั่งสุดท้ายเมื่อจบช่วง 12 วินาที การสลับชนิดยาอย่างเดียวไม่ส่ง/เปลี่ยนคำสั่งที่บันทึกไว้
- หมาป่าปกติและจ่าฝูงเห็น **🐾 เป้าหมายของฝูง** บนคนที่มีสมาชิกฝูงเลือกโจมตี คนอื่นรวม Host ปกติไม่เห็น หากฝูงเลือกคนละคนจะเห็นทุกเป้าหมาย เครื่องหมายย้าย/หายตามคำสั่งล่าสุดหรือข้าม ส่วนกรอบเขียวแสดงเฉพาะเป้าหมายของคุณ การแสดงนี้ไม่เพิ่มการโจมตีและไม่เปลี่ยนกติกานับคะแนนหมาป่า
- เครื่องหมายพลัง/ฝูงถูกล้างเมื่อจบช่วง ผลผู้หยั่งรู้ 👍/👎 ส่วนตัวยังคงอยู่ตามเดิม

## ตรวจสอบ

`npm test` ครอบคลุมที่นั่งนอกเกม ความจุ สิทธิ์ Host/GM การเตะในช่วงล็อกและปฏิกิริยา token revocation/reconnect และการไม่เปิดเผยแผนหมาป่า

`npm run test:controls` ใช้ static frontend แยก backend กับ Chromium หลาย context: Host นอกเกม + ผู้เล่น 8 คน, ยกเลิก/ยืนยันเตะ, โหวตรอบสอง, เปลี่ยนพลังแบบรวดเร็ว, marker ส่วนตัว/ฝูง, สี/กรอบ และแมตช์จนจบ จากนั้นสร้าง GM นอกเกมกับบอท 12 ตัว พร้อมภาพ desktop/mobile ใน test-results/phase-controls/
