# MOONFALL — Werewolf Online

เกมเบราว์เซอร์ภาษาไทยสำหรับผู้เล่นจริง **6–12 คนต่อห้อง** ไม่ต้องมีผู้ดำเนินเกม สร้าง/เข้าห้องด้วยรหัสหรือแชร์ลิงก์เชิญ รองรับเมาส์และคีย์บอร์ด ใช้ Node.js + Socket.IO ตัดสินกติกาที่เซิร์ฟเวอร์ และแยกหน้าเว็บ static สำหรับ Netlify

## เริ่มในเครื่อง

Node.js >=22 (ตรวจบน Node.js 24)

```sh
npm ci --cache /workspace/.npm-cache
npm start
```

เปิดเบราว์เซอร์ที่ host ของเครื่องและพอร์ต `3000` เซิร์ฟเวอร์ฟัง `0.0.0.0` เปลี่ยนได้ด้วย `PORT` ใช้ `npm run dev` ระหว่างพัฒนา ไม่มีฐานข้อมูลหรือ API key ที่ต้องใช้ในเครื่อง ฟอนต์และ Socket.IO client เสิร์ฟในเครื่อง ไม่เรียก CDN

## ลองเล่น

1. กรอกชื่อ สร้างห้อง แล้วกด “ลิงก์เชิญ” หรือคัดลอกรหัสให้เพื่อน
2. ผู้รับเปิดลิงก์ รหัสห้องจะกรอกให้ กรอกชื่อแล้วเข้าร่วม แต่ละคนใช้แท็บ/เบราว์เซอร์ของตัวเอง ไม่ duplicate แท็บที่อยู่ในห้องแล้ว เพราะอาจคัดลอก sessionStorage
3. เจ้าของห้องเลือกความเร็ว ทุกคนกดพร้อม เมื่อครบ 6–12 คนจึงเริ่มได้ คนที่ 13 ถูกปฏิเสธ
4. เปิดดูบทบาท กลางคืนเลือกเป้าหมายแล้วกดยืนยัน เปลี่ยนได้จนหมดเวลา; กลางวันคุยและโหวต
5. คะแนนเสมอมีโหวตรอบสอง นายพรานมีหน้าต่างยิงเมื่อถูกฆ่าหรือประหาร เมื่อจบเกมเปิดเผยทุกบทบาทและเล่นใหม่ได้

ช่วงโหวตและโหวตรอบสอง เมื่อยืนยันแล้วจะเห็นเครื่องหมายถูกกลางการ์ดของผู้ที่คุณโหวตให้ **เฉพาะคุณ** เปลี่ยนโหวตแล้วเครื่องหมายย้ายตาม งดออกเสียงหรือจบช่วงโหวตเครื่องหมายจะหาย รีเฟรชแล้วยังแสดงคะแนนที่ยืนยันไว้

Tab เลือกปุ่ม, Enter กด/ส่งแชต, `?` วิธีเล่น, Escape ปิดหน้าต่าง รีเฟรชแท็บเดิมเพื่อ reconnect ที่นั่งเดิม token จะถูกหมุนใหม่อัตโนมัติเมื่อกลับเข้าห้อง อย่าแชร์ session token

## Netlify + Render

ดูขั้นตอนสร้างบริการ ตั้งค่า URL และตรวจรับที่ **[DEPLOYMENT.md](docs/DEPLOYMENT.md)**

- `netlify.toml`: `npm run build` → `dist` กำหนด `PUBLIC_GAME_SERVER_URL` เป็น `https://moonfall-realtime.onrender.com` ใน build config แล้ว เปลี่ยนผ่าน Netlify environment settings ได้
- `render.yaml`: Node Web Service หนึ่ง instance, health `/health`, ตั้ง `ALLOWED_ORIGINS` เป็น Netlify origin
- กำหนด backend URL ผ่าน build configuration และเปลี่ยนได้ด้วย Environment variables; ไม่ใช้ Netlify Functions ถือห้องหรือ WebSocket และไม่ส่ง credentials ลง frontend
- ลิงก์เชิญเป็น URL Netlify พร้อม `?room=รหัส` แชร์ให้เพื่อนได้เมื่อ deploy และตั้งค่าสองบริการสำเร็จ

ผู้ใช้สร้าง Netlify ที่ `https://effulgent-alfajores-8367b8.netlify.app` และ Render ที่ `https://moonfall-realtime.onrender.com` แล้ว Backend ตอบ health และอนุญาต Netlify origin นี้ การใช้งานหน้าเว็บยังขึ้นกับ production deploy ล่าสุดสำเร็จ ขั้นตอน local build ไม่ได้ยืนยันสถานะ deploy จริง

## ตรวจสอบ

```sh
npm run check
npm test
npm run build
npm run test:browser
npm run test:vote
```

`check` ตรวจ syntax JavaScript ไม่ใช่ TypeScript typecheck โค้ดโปรเจกต์นี้เป็น JavaScript ไม่มี lint/formatter runner จึงไม่ได้อ้างว่ารัน lint หรือ typecheck ผ่าน

`npm test`: engine, exact presets 6–12, protection, seer, armor, Hunter reaction, draw, runoff, stale/replayed commands, 84 seeded headless games, 6-client network match, 12-client capacity, production origin allowlist (polling และ WebSocket) และ Netlify build validation

`npm run test:browser`: build static frontend และเปิดเซิร์ฟเวอร์ทดสอบเองที่พอร์ต 3210/3211 ใช้ Chromium `/usr/bin/chromium` หรือ `CHROMIUM_PATH` เล่นจริงผ่าน UI ทั้ง 6 และ 12 browser contexts แยกกันจนจบแมตช์ ตรวจลิงก์เชิญ คนที่ 13 บทบาท แชตลับ การโหวต reconnect rematch และมือถือ ภาพอยู่ใน `test-results/` (ignored)

เฉพาะเซิร์ฟเวอร์ทดสอบ `NODE_ENV=test` ใช้ `GAME_TIMER_SCALE` เร่งเวลาเพื่อให้ E2E ไม่กินเวลาหลายนาทีต่อแมตช์ Production ไม่รับตัวเร่งนี้ การทดสอบ headless ไม่ใช่หลักฐานความสมดุลจากมนุษย์

## ขอบเขต

ห้อง audit และเกมเก็บในหน่วยความจำเซิร์ฟเวอร์เดียว รีสตาร์ต/พักบริการแล้วหาย ไม่มีฐานข้อมูล สถิติระยะยาว บัญชี เสียงคุย บอต หรือหลาย instance ผู้หลุดยังนับเป็นผู้เล่นในแมตช์ คำสั่งที่ขาดหายข้ามเมื่อหมดเวลา ทุกคนออฟไลน์เกิน 30 นาทีห้องจะถูกลบ เจ้าของห้องนำที่นั่งออฟไลน์ออกได้เฉพาะห้องรอ Advanced/Chaos (Witch, Guard เสียสละ, Alpha, Jester) ยังไม่เปิดตาม MVP Classic ของเอกสาร

`npm run test:vote` เปิดเซิร์ฟเวอร์แยกที่พอร์ต 3221 และทดสอบเครื่องหมายโหวตส่วนตัวด้วย 6 browser contexts รวมเปลี่ยนเป้าหมาย งดออกเสียง reconnect และ runoff

`npm run test:lobby` ตรวจลิงก์เชิญ + Enter ในช่องชื่อ การรับช่วงเจ้าของห้องหลังทุกคนหลุด reconnect และ viewport มือถือ 320/360/390px (พอร์ต 3223)

`npm run test:hunter` เล่นแมตช์ 9 คนจนจบ ตรวจคืน AFK การโหวตส่วนตัว ผู้ตาย นายพรานยิงด้วย touch และการรอผลนายพรานก่อนชนะ (พอร์ต 3225)

สองคำสั่งข้างต้นรับ `PLAYTEST_BASE_URL` เพื่อทดสอบเว็บที่ deploy แล้วได้ จะสร้างเฉพาะห้อง QA ของตัวเอง และใช้เวลารอบจริงเมื่อทดสอบ production
